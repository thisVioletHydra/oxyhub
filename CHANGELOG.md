# Changelog

Minor and major versions only. Each entry is a summary. Patches are not listed.

## 0.5.0

Require semicolons. Oxlint no longer has this rule.

## 0.4.0

`catch`, `else`, `else if`, and `finally` stay on the same line as `}`.

## 0.3.0

Blank line after `if` / `for` / `try` / `switch` when more code follows. `throw` pads like `return`. An `if` with four or more checks must be a named predicate. Indent fixes settle in one pass.

## 0.2.0

Recommended config is one import. Plugin rules do not have to be listed by hand.
